# 工程图智能改图 AI

面向电机 / 泵厂的「一句话改真实 CAD 图纸」工作台。工程师用中文描述变更，
系统改的是 DWG 底层几何实体，交付黑白干净图；彩色标注只进对照图。

主路径只需要 **原始 DWG + 一句明确的中文修改要求**。参考图是可选辅助材料，
没有参考图不会影响已定标型号的正常改图。

## 现在能真实跑什么

- `TD50-40G.dwg`：H2=443 / D2=294 / 轴伸+20，真实几何变形，ODA 写回 AC1032 DWG。
- `25QYL-2SL.dwg`：标注 1:1 实测换算链、真实毫米 1:1 标定链。
- 上传后先扫描可改文字/标注：显示句柄、类型、场景、是否尺寸标注、是否共享块。
- 扫描结果支持多选、逐项填新值、统一值批量填入，再生成多条句柄指令；可展开全部可改项。
- 选中项会在图上生成全图红框和局部放大图；块内文字会展开全部 INSERT 实例定位，
  高亮只写预览副本，不改上传原图或交付 DWG。
- 修改前、修改后、局部放大和选中项定位同时生成 PNG + 矢量 SVG；页面内置细节
  查看器支持滚轮缩放、拖拽平移和最高 20×，放大后线条、尺寸数字仍保持清晰。
- 通用文字替换：如“把材料 Q235 改成 304”，唯一定位后执行；歧义时列出候选，
  并支持用“句柄 BC5”“第 2 个”“图层 A 层”锁定具体目标。
- 字段直接改值：如“把材料改成 304”“把图号改成 A-002”，只替换字段值，不误改字段名；
  标题栏 `ATTRIB` 会按 tag 定位，扫描结果还会生成可点选的指令模板。
- 尺寸数字安全边界：只写“把 610 改成 620”不会静默只改标签；必须明确
  “只改标注文字”，或改走真实毫米/几何链。
- 共享块保护：块定义被多个实例引用时，必须明确“全部修改”，避免改一处带崩全图。
- 无参考图建任务、解析、审批、执行、交付全链路可运行；参考图不参与几何计算。
- 每单都重新打开成果做独立复测，并做 DWG 往返重开校验；范围外 handle 级零改动。
- 新图纸默认拒绝几何修改，必须先定标成档案，避免拿 TD50 坐标套别的图。
- 需求不清楚时进入 `needs_instruction`，只追问，不套默认值，也不允许执行。

```powershell
cd D:\ai全栈开发\engineering-drawing-ai
python -m pip install -r requirements.txt

python app.py
# 浏览器打开 http://127.0.0.1:8900/
```

一键跑真实示例（Web）：

```text
POST /api/demo/td50?force=true&auto_execute=true
```

该示例只使用内置 DWG 和一句话要求，不绑定参考图。

命令行跑真实图纸：

```powershell
python cli.py run input\TD50-40G.dwg "H2=443, D2=294, 轴伸加20" `
  --targets "H2=443,D2=294,shaft=20" --out output\td50
```

## 四条铁律

1. AI 只出计划和解释，坐标计算与实体修改全部由确定性程序完成。
2. 彩色标注只进对照图，交付 DWG 保持原图样式，范围外零改动。
3. 数值只来自原始 CAD 与用户明确指令，不靠截图/参考图目测，不把 297 当 D2。
4. 尺寸文字与几何不能被悄悄拆开：只改标注显示必须明确授权；要真实尺寸就改几何。

## 通用改图怎么保证不误解

上传 DWG / DXF 后，工作台会扫描 `TEXT / MTEXT / ATTRIB / DIMENSION`，并把
`GS_BlockDim*` 中的尺寸文字标记为尺寸标注。自然语言进入执行前先做三道判断：

1. 是否唯一命中图纸里的真实文字/标注；多处命中就列候选，并支持句柄 / 第 N 个 /
   图层三种方式消歧后再执行。
2. 目标是不是尺寸标注；未说明“只改标注文字”就拒绝静默改数字。
3. 目标是否位于共享块；未说明“全部修改”就拒绝，避免所有实例一起变。

文本写入后重新打开成果复测：audit 0、实体数不变、几何逐条不变、目标文字写入、
非目标文字未动，再导出 AC1032 DWG 并做 ODA 往返重开。

## 可缩放细节预览

预览不再只有固定分辨率 PNG。工作台会为修改前、修改后、改动局部和选中项定位
同时生成 SVG 矢量图，并在页面上用内置查看器打开：

- 滚轮以鼠标位置为中心缩放，拖拽平移，双击放大/复位，`+` / `-` / `0` 快捷操作。
- 最大 20×，并提供“适应窗口 / 实际比例 / 新窗口打开原图”。
- SVG 探测失败时自动回退 PNG；高亮只写入预览副本，不触碰交付 DWG。
- 历史任务首次请求 SVG 时按需生成，不重新执行修改链，也不改变成果文件哈希。

## 参考图是可选的

- 上传 DWG 后直接写「风罩高度 443、接线盒伸出 294、轴伸加 20」即可生成计划。
- 参考图只作辅助沟通，不参与坐标、尺寸和目标值计算。
- 只写「按参考图改图」但没有对象和数值时，系统返回 `needs_instruction`，
  不会自动套用 H2 / D2 / 轴伸默认值。
- 新图纸仍然必须先完成档案定标；这是防止换图改错的安全边界，与是否上传参考图无关。

## 换型号

代码里不再有 TD50 坐标常量。换型号 = 给新图纸建档案：

```powershell
python cli.py calibrate input\新图纸.dwg --id new-model --title "新图纸安装图"
# 按生成的 draft/scan 人工确认 handle、定标、基准、原值
python cli.py profiles install knowledge\drawings\new-model.draft.json
python cli.py run input\新图纸.dwg "H2=443, D2=294, 轴伸加20"
```

未达到 `review.status=confirmed`、关键 handle、定标、基准齐全的档案不允许安装。

## 运行边界

- DWG 写回依赖 ODA File Converter；没有 ODA 时只能读图/出 DXF，不能交付 DWG。
- 几何规则目前覆盖 TD50 这一类立式泵安装图；其他结构需新增档案与必要的规则区域。
- 任务存储是文件型 JSON，适合单机工作台；并发、多用户、权限与数据库化尚未实现。
- `server.py` 保留为 v1 兼容入口，实际启动的是同一套 FastAPI 应用。
- `legacy/` 存放已归档的旧执行器、旧前端和历史脚本，不再参与主链路。
