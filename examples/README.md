# Sample Drawing

`sample.dxf` is a synthetic plate drawing with a material field, a drawing number,
and a dimension for testing the workbench.

To try the workbench:

1. Install the [project dependencies and ODA File Converter](../README.md#快速开始).
2. Start the service with `python app.py` and open the [workbench](http://127.0.0.1:8900/).
3. Upload `examples/sample.dxf` and scan the editable text items.
4. Enter `把材料改成 304`, review the planned edit, and confirm execution.
5. Check the before and after previews and download the verified drawing.
