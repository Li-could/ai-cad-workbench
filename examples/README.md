# Sample Drawing

`sample.dxf` is a small synthetic DXF used to exercise the upload, text scan, and text-edit UI.

It is not a production drawing and contains no customer geometry.

To try the workbench:

1. Start the service with `python app.py`.
2. Open `http://127.0.0.1:8900/`.
3. Upload `examples/sample.dxf`.
4. Scan the editable text items.
5. Use a text-only instruction to verify the review and delivery flow.
